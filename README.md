# 복지업무 도우미

주민센터 사회복지 업무용 정적 웹페이지 모음입니다. 서버·인터넷 없이 `index.html`을 더블클릭해 브라우저로 열면 됩니다.
(외부 사이트 링크와 검색 버튼만 인터넷이 필요합니다.)

| 페이지 | 용도 |
|---|---|
| `index.html` | 홈 — 통합 검색창, 올해 기준 중위소득 요약 |
| `docs.html` | 참조문서 검색 — 법령·사업안내·기관 사이트 + 내 문서 등록/검색, 외부 사이트 바로 검색, 결과 목록 복사 |
| `calc.html` | 선정기준 계산 — 가구원 수별 급여 선정기준, 소득인정액 비교, 생계급여 예상액, 소득인정액 간이 추정 |
| `checklist.html` | 구비서류 체크리스트 — 사업별 서류(공통 서류 자동 합치기), 안내문 인쇄 |
| `deadline.html` | 처리기한 계산 — 법정 기한, 공휴일·주말 반영, 근무일 수 |
| `counsel.html` | 상담기록 작성 — 항목 입력 → 항목형/서술형 상담내용 문장 (저장하지 않음) |
| `templates.html` | 안내 문구 — 문자·공문 틀에 빈칸 채우기, 바이트 수, 내 문구 저장 |

## 매년 고칠 곳

- `assets/data.js` — 기준 중위소득, 급여별 비율, 재산 공제액, 공휴일, 기한 규칙
  - **2027년 기준 중위소득은 1인·4인만 들어 있습니다.** 고시 원문으로 2·3·5·6인을 채우고 `verified: true`로 바꾸세요.
  - 재산 공제액·환산율(`asset`)도 해당 연도 사업안내로 확인하세요.
- `assets/docs-data.js` — 기본 참조문서 목록, 외부 검색 주소
- `checklist.html` 안의 `PROGRAMS` — 사업별 구비서류

## 저장 방식

'내 문서', '즐겨찾기', '내 문구', 기관명·담당자·연락처는 이 PC 브라우저(localStorage)에만 저장됩니다.
다른 PC로 옮길 때는 참조문서 검색의 **내 문서 내보내기/가져오기**를 쓰세요. 상담기록은 저장하지 않습니다.
